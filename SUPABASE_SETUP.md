# Arizona Interior Exterior – Supabase Setup

1. Open your Supabase project.
2. Go to **SQL Editor** → **New query**.
3. Open `supabase-schema.sql`, copy everything and run it.
4. In the website folder, run:
   `npm install`
   `npm run dev`
